▸ trick plays

These are unusually safe in this league. Only one forward pass is allowed per down, but backward pitches are unlimited, and a dropped pitch is a dead ball that we keep rather than a turnover. The worst realistic outcome on any of these is a loss of yards. The rules reasoning is spelled out on each one so we can explain it to the referee if he asks.

One per game, maximum two. Every one of these works because it looks like a play we have already run for real yards, so run the real play first.
